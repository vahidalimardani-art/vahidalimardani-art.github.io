# وب‌سایت وحید علیمردانی

این وب‌سایت با GitHub Pages و Jekyll منتشر می‌شود و تمام محتوای روزمره آن از طریق Pages CMS مدیریت می‌شود.

برای مدیریت محتوا، صفحه `/admin/` را باز کنید و وارد Pages CMS شوید. در پنل می‌توان آثار، یادداشت‌ها، صفحه درباره و اطلاعات ارتباطی را بدون ویرایش کد یا فایل‌های فنی تغییر داد.

محتوای منتشرنشده با گزینه «انتشار» از سایت عمومی پنهان می‌ماند. نام فایل آثار و یادداشت‌ها خودکار ساخته می‌شود.
